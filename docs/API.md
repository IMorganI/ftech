# API для сайтов

Все запросы — JSON по HTTPS. Суммы — **целые числа в минорных единицах** (центы): `2500` = 25.00 EUR.

## Авторизация

```
Authorization: Bearer ftk_...
```

Ключ выдаётся сайту один раз при создании; у нас хранится только его хэш. Ключ можно отозвать.
Без ключа или с неверным ключом — `401`.

Ограничение частоты: по умолчанию 600 запросов в минуту на ключ, сверх — `429`.

## Создать депозит

```
POST /v1/deposits
Idempotency-Key: order-2026-000123      ← обязательно, 8–128 символов
```

```json
{
  "amount": 2500,
  "currency": "EUR",
  "player": {
    "id": "u42",
    "country": "MT",
    "kyc": "verified",
    "depositLimitDaily": 50000,
    "selfExcluded": false
  }
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `amount` | да | Целое > 0, в центах. Можно строкой: `"2500"` |
| `currency` | да | ISO 4217: `EUR`, `BRL`, `CAD`… |
| `player.id` | да | ID игрока на стороне сайта |
| `player.country` | да | ISO 3166-1: `MT`, `DE`, `BR`… |
| `player.kyc` | нет | `none` (по умолчанию), `pending`, `verified`, `rejected` |
| `player.depositLimitDaily` | нет | Лимит депозитов игрока за сутки (UTC), в центах |
| `player.selfExcluded` | нет | `true` — игрок в самоисключении |

**Ответ** `201` (новый платёж) или `200` (повтор с тем же `Idempotency-Key`):

```json
{
  "id": "e68b2670-321e-4fdb-a9e9-cf5c2c76031c",
  "type": "deposit",
  "status": "pending",
  "amount": "2500",
  "currency": "EUR",
  "declineCode": null,
  "createdAt": "2026-11-11T21:48:22.639Z",
  "updatedAt": "2026-11-11T21:48:22.639Z"
}
```

Отказ — это тоже успешно созданный платёж (`201`) со `status: "declined"` и причиной в `declineCode`:

| `declineCode` | Что значит |
|---|---|
| `player_self_excluded` | Игрок в самоисключении |
| `country_not_licensed` | Страна игрока не входит в лицензии оператора |
| `kyc_rejected` | KYC игрока отклонён |
| `kyc_required` | Сумма выше порога оператора, а KYC не подтверждён |
| `player_limit_exceeded` | Превышен дневной лимит игрока |
| `no_route` | Нет мерчант-аккаунта, который принимает этот платёж сейчас |
| `all_attempts_failed` | Провайдеры отклонили платёж на всех попытках |

**Повторы.** Повторяй запрос с тем же `Idempotency-Key` сколько угодно — второй платёж не создастся.
Тот же ключ с другими параметрами — `409 idempotency_conflict`.

## Статус депозита

```
GET /v1/deposits/{id}
```

Отдаёт тот же объект. Сайт видит только свои платежи; чужой или несуществующий — `404`.

## Ошибки

```json
{ "error": { "code": "invalid_request", "message": "...", "details": [...] } }
```

`400` — ошибка в запросе, `401` — авторизация, `404` — не найдено, `409` — конфликт идемпотентности,
`429` — слишком часто, `500` — внутренняя ошибка (подробности только в наших логах).
